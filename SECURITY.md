# Security Policy

## Reporting a Vulnerability

If you've found a security issue in one of my projects, please report it privately rather than opening a public issue.

**Preferred: [Report via GitHub Security Advisories](https://github.com/Surajkumarsaw1/Surajkumarsaw1/security/advisories/new)**
This creates a private report only visible to me until it's resolved.

If you're unable to use GitHub Security Advisories, you can also open a regular [GitHub Issue](https://github.com/Surajkumarsaw1/Surajkumarsaw1/issues/new) on this repo — please avoid including exploit details in the public issue and I'll follow up for specifics privately.

## Scope

This policy covers repositories under [github.com/Surajkumarsaw1](https://github.com/Surajkumarsaw1).

## Response

I aim to acknowledge reports within a few days. This is a personal account, not a funded security program, so response times may vary.
